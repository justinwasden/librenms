===============================================================================
KEY DATABASE CHANGES
===============================================================================

NEW TABLE: device_api_metrics
  - device_id (FK to devices)
  - api_endpoint_id (FK to rest_api_endpoints)
  - api_connection_id (FK to rest_api_connections)
  - resource_type (array, volume, interface, host)
  - resource_id (UUID or unique identifier)
  - resource_name (human-readable name)
  - metric_name (capacity, speed, etc.)
  - metric_type (gauge, counter)
  - value (numeric values)
  - string_value (text/JSON values)
  - collected_at, created_at, updated_at

MODIFIED TABLE: rest_api_endpoints
  + resource_type VARCHAR(50)
  + resource_id_path VARCHAR(255)
  + resource_name_path VARCHAR(255)
